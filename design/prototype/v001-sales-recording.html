🎯 本版目标

  • 补全「排程 → 生产 → 销售回录」闭环：逐菜录入/CSV 导入实际售出份数，工作台自动切换复盘视图。
  • 复用已有资产：schedule_items.actual_sold_qty 字段、/api/dashboard/daily 复盘计算、「待回录」占位，零迁移成本。
  • 前置文档：docs/销售数据回录-讨论.md → docs/v001-销售数据回录-方案.md

📐 信息架构

  • 工作台当日复盘单卡片：三种派生态（未回录 / 部分回录 / 已回录）由明细行聚合而成。
  • 回录弹窗双 Tab：手动录入（逐菜输入 + 售罄快捷）/ 批量导入（模板 → 解析预览 → 确认）。
  • 复盘视图：售出进度条 + 偏差 + 销售额，按售出率降序（滞销菜沉底标黄），超售标红。

⚡ 交互规则

  • 部分回录可保存；售出列空 = 未录，允许随后继续。
  • 售出 > 计划不阻断，行内红 badge「超售 +N」；售出率 < 60% 行标黄提示滞销。
  • 导入预览五种行状态：匹配成功 / 将覆盖 / 重复自动合并 / 未匹配（下拉选菜或忽略）/ 售空跳过。
  • 修改已回录需二次确认；底部实时汇总「已录 x/y 道 · 售出合计 · 预计售出率」。
  • 校验：整数 0~9999，非法输入行内红框并阻断保存。

🎨 视觉规范

  • 颜色：oklch 语义变量（--primary 橙棕 oklch(0.553 0.195 38.402) / --success 绿 / --destructive 红）
  • 圆角：卡片 12px，按钮/输入 8px，badge 4px；字体：系统字体栈 + 等宽数字
