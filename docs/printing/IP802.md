# 印麦 IP802 净菜标签打印配置

## 使用前提

- 打印机通过 USB 连接当前操作生产计划单的 Windows 电脑。
- 使用 Chrome 或 Edge 打开精益厨房系统。
- 标签纸规格为 50×40mm。

## 安装与纸张设置

1. 安装厂商提供的 IP802 Windows 驱动，确认 Windows「打印机和扫描仪」中出现对应打印队列。
2. 打开 IP802 的「打印首选项」，将纸张尺寸设置为 50×40mm，方向为纵向。
3. 如果驱动中没有 50×40mm，打开 Windows「打印服务器属性」→「表单」，新建宽度 5cm、高度 4cm 的表单，再回到打印首选项选择该表单。
4. 在浏览器打印对话框中设置：
   - 打印机：IP802 对应队列
   - 纸张：50×40mm
   - 页边距：无
   - 缩放：100%
   - 页眉和页脚：关闭

## 系统操作

1. 打开生产计划单详情。
2. 点击「打印净菜标签」。
3. 系统生成整张生产计划单的全部净菜标签，并打开浏览器打印对话框。
4. 确认打印设置后打印；取消对话框后可在标签页点击「打印全部标签」重新打印。

标签内容依次为净菜名称、封装规格、生产日期。生产日期取实际触发打印时的本地日期。

## 常见问题

- **没有 IP802 选项**：检查 USB 连接、驱动安装和 Windows 打印队列状态。
- **打印后内容缩小或偏移**：确认纸张为 50×40mm、缩放为 100%、页边距为无。
- **连续打印出现空白页**：检查驱动纸张高度是否准确设置为 40mm，并关闭浏览器页眉页脚。
- **标签内容被裁切**：确认驱动方向和纸张方向均为纵向，检查标签纸传感器与间距校准。
- **打印内容跑到页面左上角或带网址**：关闭浏览器页眉页脚，并在打印预览中确认只显示标签。
