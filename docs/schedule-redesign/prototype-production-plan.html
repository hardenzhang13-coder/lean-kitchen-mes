切配中心生产计划单 · 功能原型

需求：把各门店「进行中」排程单的切配工单与采购计划按净料/食材维度跨店汇总，生成切配中心生产计划单。
流程：排程管理新增「生产计划单」模块 → 新增（标题 + 日期 + 勾选进行中排程单）→ 生成 → 详情（汇总切配 + 汇总采购 + 打印/导出）。

项口径说明
新表ProductionPlan（生产计划单）id / code（PPL-日期-序号，与 SCH 同规则） / title / planDate / operator / createdAt；快照语义：生成时固化，之后门店排程变化不影响
关联表ProductionPlanScheduleplanId + scheduleId（记录汇总的来源排程单，便于溯源）
汇总切配按 (sourceType, sourceId) 跨店合并净料用量=Σ各单；切配份数=合并量÷封装规格重算（formatPortions）；毛料用量=经来源原料取汇总采购行；行内展示门店分布（从各单明细按门店分组求和）
汇总采购按 (sourceType, sourceId) 跨店合并毛需求=Σ各单克数；库存扣减=合并后毛需求(斤) 对当前库存重新抵扣一次（避免多单重复扣库存）；建议采购量按三条取整规则重算；预估金额=采购口径金额；供应商取食材档案默认供应商
可选范围仅 status=进行中 的排程单待生效/已完成不可选（避免计划外与已结束数据混入）；勾选列表显示编号/门店/菜品/份数
打印/导出复用门店单据版式切配单（含完成状态空栏☐）与采购单（采购量留白）与门店版字段一致；采购单支持按供应商拆单打印
权限/操作与排程单一致创建/删除记操作日志；删除走标准二次确认弹窗
