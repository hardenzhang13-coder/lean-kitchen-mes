## 一、产品目标

切配中心库存只管理**净菜**（净料 + 小料），形成闭环：

```
排程分解 → 切配工单 ──【完成生产】确认──▶ 净菜入库 ──▶ 当前库存
                                              │
门店要货 ──▶ 创建出库单（按实际库存算可出量）──▶ 净菜出库 ──▶ 出库单打印/作废回滚
```

**Success 标准**：完成生产提交后 1 秒内库存列表可见；出库单可出量与实际入库严格一致，未切配项在单据上不可遗漏；所有进出有台账、有操作人。

## 四、状态机

### 4.1 切配工单

```
pending ──完成生产提交──▶ completed（带 completed_qty）│ unfinished（带 remark，当日终态）
```

- 提交粒度：一次提交包含 N 行，每行独立落状态；事务提交。
- 排程状态联动：排程下不存在 pending 工单 → 排程自动「已完成」；否则保持「进行中」，可再次发起【完成生产】（弹窗仅列 pending 行）。

### 4.2 出库单

```
confirmed ──作废（二次确认+原因）──▶ voided（事务内回滚：库存 += 各明细 shipped_qty，写 stock_rollback 流水）
```

- 创建即 confirmed（=发货凭证），同时事务内扣减库存。

## 五、核心流程与规则

### 5.1 完成生产（F1/F2）

入口：排程详情【完成生产】（仅 status=进行中 显示）。

弹窗「完成生产确认」：
- 表格列：一级分类 | 二级分类 | 编号 | 名称 | 规格 | 切配量(g) | 实际完成量(g) | 状态 | 备注
- 每行状态默认「完成」：实际完成量输入框启用，默认=切配量，可改小（支持部分完成，不允许改大、不允许负数）。
- 改为「未完成」：实际量输入禁用置空，备注选填。
- 底部汇总：本次入库 N 种共 X g · 未完成 M 种。
- 提交校验：实际量为正数；事务内：更新工单 → 库存增加 → 写台账（balance_after 逐条刷新）→ 判排程终态。
- 再次打开：仅列 pending 行，已确认行只读展示在弹窗下方折叠区；提交后若仍有 pending 行，排程保持「进行中」，按钮显示剩余待确认数。

### 5.2 创建出库单（F4）

入口：库存模块【创建出库单】。

- **第 1 步 选择**：门店（卡片选择）→ 该门店 status ∈ {进行中, 已完成} 的排程（卡片：编号/日期/菜品·份数/工单完成度），选中进入下一步。门店与排程绑定（排程含 store_id），切门店即刷新排程候选。
- **第 2 步 明细**：自动带出该排程全部切配工单行（净料+小料，按一级/二级分类分组排序），列：
  一级分类 | 二级分类 | 序号 | 名称 | 规格 | 份数 | 净料用量(g) | 当前库存(g) | **本次出库(g，可编辑）** | 状态
- 行状态判定（展示徽标，提交不受阻断）：
  - `unfinished` 未切配：工单 pending → 本次出库默认 0，行标红
  - `insufficient` 量不足：工单完成但 completed_qty < required，或库存 < 需求 → 默认带出 min（需求， 库存）
  - `normal` 正常
- 本次出库规则：默认 = min(净料用量, 当前库存)；可改 0..当前库存；超过库存即时校验拦截。
- 汇总条：共 N 行 · 计划 X g · 本次出库 Y g · 未切配 M 行（红色）。
- 提交：事务内重新读取库存校验 → 生成主表+明细（快照）→ 扣库存 → 写台账 → 跳详情页。

### 5.3 出库单详情/打印/作废（F5）

- 头部：单号 / 门店 / 排程编号 / 生产日期 / 制单人+时间 / 状态 / 备注。
- 明细表：同 5.2 列 + 状态列；未切配/量不足行红色徽标。
- 打印：独立打印页（仿排程打印），打印时间、操作人。
- 作废：标准 Dialog 二次确认 + 必填原因 → 事务回滚（呼应红线）。

### 5.4 当前库存（F3）

- 列表列：一级分类 | 二级分类 | 编号 | 名称 | 类型（净料/小料） | 当前库存（g，≥1000g 显示「X 斤 Y g」） | 最近变动时间。
- 顶部 KPI：净菜种类 / 库存总量（斤） / 今日入库 / 今日出库。
- 筛选：搜索（名称/编号）+ 一级分类宫格 + 类型筛选；分页（每页 20）。
- 数据源：prepped_stock join 净料/小料档案（软删除过滤）。

### 5.5 出入库流水（F6）

列：时间 | 类型（入库/出库/作废回滚） | 净菜（分类+名称+编号） | 变动量(g) | 结存(g) | 来源单据（生产入库/SCH-xxx、出库单 OUT-xxx 可跳转） | 操作人。分页 + 类型筛选。

## 九、边界与异常

1. **并发出库**：创建出库单事务内 `UPDATE prepped_stock SET current_qty = current_qty - ? WHERE ... AND current_qty >= ?` 条件更新，影响行数=0 即报库存已变化，请刷新。
2. **库存为负**：任何路径不允许；校验在 API 层 + 数据库条件更新双保险。
3. **排程编辑/删除**：已有完成入库的排程不允许删除（引用检查）；待生效排程维持现有删除规则。
4. **作废出库单后库存回到哪**：直接加回汇总库存（不分批次），台账记录 rollback 来源。
5. **净料/小料档案软删除**：有库存或台账的档案不允许删除（引用检查）。
6. **完成生产重复提交**：前端按钮 loading + 服务端按行状态幂等（已终态行忽略/报错）。
